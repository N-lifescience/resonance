# 기능 목록 (인터뷰 ③에서 보여 줄 원본)

인터뷰에서 이 목록을 통째로 보여 주지 않는다. PPT를 읽고 **이 수업에 맞는 것만 6~10개** 골라 번호를 붙여 보여 준다.
핵심 기능 넷(HTML 자동 생성 및 편집 / 익스플로라그램 탑재 / 실시간 수업 / 전자칠판 기능 탑재)으로 묶어 보여 준다.
맞는 것에 (추천)과 **PPT의 어느 장 때문인지** 한 줄 이유를 붙인다. 부품 이름 대신 교사가 알아듣는 말로 쓴다. 없는 기능은 있다고 하지 않는다.

## 늘 들어가는 것 (고를 필요 없음)

엔진이 모든 수업 파일에 넣는다. 목록 위에 "이건 늘 들어가요"라고 한 줄로 알린다.
판서(펜·형광펜·지우개·레이저, 장마다·반마다 저장), 칠판, 넘기기, 인쇄, 편집 모드, 자동 점검, 실시간 수업(「실시간」 → 코드·QR, 학생 화면이 교사 화면을 따라옴, 교사 판서가 학생 화면에 보임), ⚙ 기능 켜고 끄기.

## 1. HTML 자동 생성 및 편집

| 기능 | 이럴 때 추천 | 쓰는 것 |
|---|---|---|
| 원본 PPT 모양 살리기(머리 띠·배지·색) | 원본 PPT에 뚜렷한 틀이 있음 | `references/design.md`의 '원본 PPT의 얼굴' |
| 장 순서를 수업 흐름에 맞게 바꾸기 | 개념 설명과 활동이 뒤섞여 있음 | 장 재배치, 쪽 번호 가리킴 고치기 |
| 그림 자리에 원본 PPT 그림 채우기 | 코드를 실행할 수 없는 환경, 그림이 많은 PPT | `img[data-ppt]` + ⚙ 「그림 넣어 저장」 |
| 인터넷 없는 교실용 파일 | 교실 인터넷이 불안정함 | `bundle.py --offline` |

## 2. 익스플로라그램 탑재

익스플로라그램 장면은 헷갈리는 지점마다 장면 두세 개를 보여 주고 축(시간·공간·시공간)도 함께 고른다(`references/exploragram.md`의 '장면 메뉴').

| 기능 | 이럴 때 추천 | 쓰는 것 |
|---|---|---|
| 시간이 흐르며 그림과 그래프가 변하는 장면 | 실험 결과가 시간에 따라 달라짐(확산, 반응, 성장) | 계산 상자 + 그래프 + `data-play` |
| 값을 바꾸면 그림·수치·식이 함께 바뀌는 장면 | 변수와 결과의 관계가 핵심(가격, 농도, 기울기) | `.calc` + `figure.plot` |
| 입자나 신호가 퍼지고 옮겨 가는 장면 | 확산, 삼투, 전도처럼 무언가 이동함 | `figure.particles` + 계산 상자 |
| 그래프 위 점을 끌어 옮겨 보는 장면 | 점의 위치로 관계를 비교함 | `figure.plot` + `data-drag` |
| 한 단계씩 여는 과정 | 순서대로 나타나는 과정(세포 주기, 풀이) | 단계 막대 `.reveal`, `.step` |
| 지도에서 지역을 차례로 열기 | 영역·세력의 변화 | `figure.map-reveal` |
| 연도와 사건을 차례로 열기 | 사건의 순서가 중요함 | `ol.yearline` |
| 두 경우를 바꿔 가며 비교 | 전후·조건 비교 | `.switch` |
| 확인 문제(보기마다 이유) | 익스플로라그램 뒤 이해 확인 | `.quiz` |
| 분류 카드 | 용어·사례를 범주로 나눔 | `.sort` |
| 순서 배열 | 순서가 바뀌면 뜻이 달라짐 | `ol.order` |
| 그림에 이름표 붙이기 | 구조·위치를 찾아야 함 | `figure.labeling` |
| 한 줄 답 쓰기 | 학생의 예상이나 설명을 듣고 싶음 | `.short` |

## 3. 실시간 수업

실시간 수업 자체는 늘 들어간다. 여기서는 **학생 답이 교사 화면에 모이는 활동**을 고른다.

| 기능 | 이럴 때 추천 | 쓰는 것 |
|---|---|---|
| 학생이 고른 값을 막대로 모아 칠판에 띄우기 | 학생마다 값을 바꿔 보는 익스플로라그램이 있음 | 계산 상자 슬라이더(「학생 보기」에 모임) |
| 확인 문제 답을 보기별 인원으로 모으기 | 반 전체 이해를 바로 보고 싶음 | `.quiz` |
| 의견 투표 | 정답이 없는 물음 | `.poll` |
| 한 줄 답 모으기 | 생각 열기, 예상 적기 | `.short` |

## 4. 전자칠판 기능 탑재

판서와 칠판은 늘 들어간다. 장 안에 넣는 교실 도구를 고른다.

| 기능 | 이럴 때 추천 | 쓰는 것 |
|---|---|---|
| 타이머 | 제한 시간 활동, 모둠 토의 | 교실 도구 타이머 |
| 발표자 뽑기 | 발표·질문 순서 정하기 | `.picker` |
| 모둠 점수판 | 모둠 활동, 퀴즈 대항 | `.score` |
| 체크리스트 | 실험 준비물, 활동 절차 확인 | 교실 도구 체크리스트 |
| 영상·사이트 카드 | 교사가 준 영상·사이트 주소가 있음 | `.video`, `a.link-card` |
