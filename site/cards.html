강사 카드

유명 강사의 화법을내 수업의 대본으로

  1. 강사 카드 만들기유튜브 강의 영상을 Gemini가 보고, 설명·질문·비유·유머 방식을 카드로 정리합니다. 강사마다 한 번이면 됩니다.
  2. 수업 HTML 만들기제작하기에서 쓰던 AI로 수업 HTML을 만듭니다.
  3. 대본 묶음 저장아래 「대본 묶음」에서 화법 항목마다 카드를 고르고 파일 하나로 저장합니다.
  4. 대본 받기쓰던 AI에 수업 HTML과 묶음 파일을 올리고 부탁합니다. AI가 묻고 설계표를 확인받은 뒤 대본을 줍니다.

카드는 이 브라우저에만 저장됩니다. 이름·학교·연락처는 받지 않습니다. 학교 PC가 재부팅 때 기록을 지운다면 맨 아래 「보관함 백업 파일로 저장」을 쓰세요.

카드 만들기

유머가 잘 드러나는 3~10분 구간부터 분석해 보세요. 이미 분석한 영상과 구간은 다시 분석하지 않습니다.

Gemini 키로 바로 분석

내 Gemini API 키로 영상을 차례로 분석합니다. 분석하는 동안 이 탭을 닫지 마세요. 사용량은 내 Google 계정 한도에서 나갑니다.

대본 묶음

화법 항목마다 카드를 고르세요. 비워 두면 그 항목은 기본 화법으로 씁니다. 같은 카드를 여러 항목에 골라도 카드 내용은 한 번만 들어갑니다.

이 묶음 파일의 지침대로 이 수업 HTML로 대본 써줘

쓰던 AI에 수업 HTML과 묶음 파일을 함께 올리고 위 문장을 붙여 넣으세요. 대본이 길면 AI가 묶음마다 끊어 씁니다. 「계속」이라고 쓰면 이어서 씁니다.

백업과 안내

카드 파일(.md)은 수업자료제작기(class-helper)의 강사 카드도 불러옵니다.

기기 밖으로 나가는 것

  • 「Gemini로 분석」을 누르면 유튜브 주소와 분석 요청문이 내 키로 Google Gemini에 갑니다.
  • 카드의 기본 사진은 유튜브 이미지 서버에서 받습니다.
  • 이 쪽의 파일은 GitHub Pages에서 받습니다.

이 밖의 정보는 어디에도 보내지 않습니다. 카드와 묶음 파일에는 강사의 실제 말이 짧게 들어 있습니다. 개인 수업 참고용으로만 쓰고 인터넷에 공개하지 마세요.
