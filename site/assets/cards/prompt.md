## 12. 동기유발과 마무리의 이야기 구조

- 마무리: 처음의 질문을 다시 받는지, 개념을 생활/다음 탐구로 확장하는지, 감정·호흡의 변화와 근거 장면.
- 배경지식이 어디서 등장하고 어떤 연결 대사로 개념으로 돌아오는지 적는다.
- 해당 구간을 확인하지 못했다면 '확인 못 함'으로 적는다. 응용 제안을 적을 때에는 '새 수업을 위한 제안(관찰 사실 아님)'으로 분리한다.

## 13. 고유한 유머·비유·화법 지문
- 유머 장면마다 [시각] 전제 → 웃음을 만드는 반전/과장/상황극 → 받아치기 → 개념 복귀를 분석한다. 관찰한 장면이 없으면 없다고 쓴다.
- 비유 사전: 비유 소재 / 설명한 개념 / 연결 관계 / 익살스러운 표현 방식 / 한계. 이 영상에서 확인한 것만 쓴다.
- 짧은 말버릇·호칭·문장 끝맺음·반문·반복 리듬을 상황별로 기록한다. 원대사 인용은 각 예시의 최소 구절로 제한하고 긴 대사는 요약한다.
- 한 번 나온 표현과 반복 관찰된 습관을 구별한다. 강사 이름만 보고 고정관념으로 채우지 않는다.

각 항목은 [시각·짧은 근거] → [재사용할 기법] → [새 주제에서 쓸 문장 구조]로 짧게 정리한다. 위 항목을 반복 복사하지 않는다.
