확산이란?

개념

확산물질을 이루는 입자가 스스로 움직여 다른 물질 속으로 퍼져 나가는 현상

입자는 끊임없이 스스로 움직이기 때문에 확산이 일어난다.

생활 속 확산

  • 향수 냄새가 방 안에 퍼진다.
  • 물에 잉크를 떨어뜨리면 물 전체로 퍼진다.
  • 티백을 넣은 물의 색이 점점 진해진다.

실험: 물의 온도와 확산

실험

물의 온도가 다르면 잉크가 퍼지는 빠르기는 어떻게 달라질까?

준비물

  • 비커 2개
  • 잉크
  • 찬물(10 ℃)
  • 스포이트
  • 따뜻한 물(60 ℃)
  • 초시계

※ 뜨거운 물에 손을 데지 않게 조심한다.

실험 방법

실험
  1. 비커 2개에 찬물과 따뜻한 물을 200 mL씩 담는다.
  2. 물이 잔잔해질 때까지 1분 동안 기다린다.
  3. 두 비커에 잉크를 한 방울씩 동시에 떨어뜨린다.
  4. 잉크가 비커 전체에 고르게 퍼질 때까지 걸린 시간을 잰다.
  5. 결과를 표에 기록한다.

비커를 흔들거나 젓지 않는다. 저으면 확산이 아니라 섞기가 된다.

확산

증발

ㄱ. 꽃향기가 정원 전체에 퍼진다. ㄴ. 어항의 물이 조금씩 줄어든다. ㄷ. 물에 설탕을 넣으면 저어 주지 않아도 물 전체가 달아진다. ㄹ. 손등에 바른 알코올이 금방 마른다. ㅁ. 모기향 냄새가 방 안에 퍼진다. ㅂ. 마당에 뿌린 물이 마른다.

확산: ㄱ, ㄷ, ㅁ   증발: ㄴ, ㄹ, ㅂ

정리
