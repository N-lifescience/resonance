# 공명 라이트(lite) 설계

## 왜 만드나

마주온 같은 교육청 AI의 기본 모델은 긴 HTML과 계산식을 정확히 쓰지 못한다. 시험에서 엔진 부품 문법을 잘못 쓰고, `Math.min` 같은 자바스크립트를 식에 섞고, 장이 넘치고, 답이 20KB에서 잘렸다.

그래서 모델은 **마크다운과 비슷한 '수업 글'만** 쓴다. `lite.js`가 그 글을 엔진 HTML(`section.slide`, 부품, 익스플로라그램)로 펼친 뒤 공명 엔진을 불러온다. 익스플로라그램은 모델이 짜지 않는다. 미리 만들어 점검한 **틀**에 값만 채운다. 23장짜리 수업이 8KB 안팎이라 한 답에 들어간다.

## 1. 파일 모양(모델이 쓰는 전부)

```html
<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>전하를 띠는 이온</title>
<script src="https://cdn.jsdelivr.net/gh/N-lifescience/resonance@BRANCH_OR_SHA/lite/lite.js"></script>
</head>
<body>
<script type="text/x-lesson">
색: #568A35

# [표지] 전하를 띠는 이온
중학교 2학년 과학 · Ⅰ. 물질의 구성

# 학습 목표
- 이온의 형성 과정을 모형과 이온식으로 표현할 수 있다.
</script>
</body>
</html>
```

- 수업 글은 `<script type="text/x-lesson">` 안에 쓴다. `<script type="text/plain" id="lesson">`도 받는다.
- `lite.js`의 `data-engine` 속성으로 엔진 폴더 주소를 바꿀 수 있다(시험용). 기본값은 `https://cdn.jsdelivr.net/gh/N-lifescience/resonance@2/engine/`.

## 2. 수업 글 문법

한 줄씩 읽는다. 모르는 줄은 문단으로 보여 준다(오류로 멈추지 않는다). 앞뒤 빈칸, 전각 기호(＃, －, ＞, ［ ］, ｜), `•`, `·` 목록 표시, `->`/`→`는 너그럽게 받는다.

### 2-1. 설정(첫 장 앞)
| 줄 | 뜻 |
|---|---|
| `색: #568A35` | 강조색과 띠 색(`--accent`, `--tab`). 글자색은 흰색 |
| `덱: sci-2-ion` | 판서 저장 열쇠. 없으면 `<title>`로 만든 짧은 해시(`lite-xxxxxx`) |

### 2-2. 장
| 줄 | 결과 |
|---|---|
| `# 제목` | 새 장. `<section class="slide" id="s{n}" data-title="제목">` + `<h2>제목</h2>` |
| `# [표지] 제목` | 표지 장. 다음 줄들은 꼬리표(`p.kicker`, 첫 줄만)와 무시. `<section class="slide cover"><div class="band"><p class="kicker">…</p></div><h1>제목</h1></section>` |
| `# [장표지] 2. 이온의 이동` | `<section class="slide chapter" data-sec="2. 이온의 이동"><p class="kicker">2</p><h1>이온의 이동</h1></section>`. 이 뒤 장들의 `data-sec`도 이 이름이 된다 |
| `[묶음] 1. 이온` | 이 뒤 장들의 `data-sec`(장을 만들지 않음) |

`id`는 `s1`, `s2`…로 붙인다(장 나누기로 생긴 장은 `s7b`).

### 2-3. 장 안의 줄
| 줄 | 결과 |
|---|---|
| `문장` 또는 `- 문장` | `<p>` |
| `> 문장` | `<p class="step">`(→ 키로 열림) |
| `Q. 물음` 또는 `Q 물음` | `<p class="q" data-n="Q">물음</p>` |
| `답: 문장` 또는 `A. 문장` | `<div class="answer"><p>문장</p></div>` |
| `[꼬리표] 글` | `<p class="kicker">` |
| `[그림 7-4] 설명` | 그림 자리(2-5) |
| `[영상] https://… | 제목` | `<div class="video" data-youtube="주소" data-title="제목"></div>`. 주소가 http로 시작할 때만 |
| `| 가 | 나 |` 로 시작하는 연속 줄 | 비교표. 첫 줄이 머리(`thead`), 각 줄 첫 칸은 `th`. `|---|` 줄은 버린다 |
| `[AI] 문장` | AI가 새로 쓴 문장. `<p data-ai="AI 작성">` |

글 안 표시: `{정답}` → `<span class="blank">정답</span>`, `**굵게**` → `<b>`, `==형광==` → `<mark>`. `<`, `>`, `&`는 글자로 이스케이프한다(학생 글을 HTML로 넣지 않는다).

### 2-4. 활동(줄 맨 앞 `[이름]`으로 시작하는 덩어리)
덩어리는 빈 줄, 다음 `#`, 다음 `[이름]`에서 끝난다. 한 장에 활동은 하나만 둔다. 활동 앞의 문장은 활동 위에 놓는다.

**퀴즈**
```
[퀴즈] 중성 원자가 전자를 잃으면 무엇이 될까?
- 음이온 | 전자를 얻으면 음이온이 된다.
* 양이온 | 맞다. 전자를 잃으면 (+)전하가 더 많아진다.
- 중성 원자 | 전자 수가 바뀌면 중성이 아니다.
```
`*`가 정답(여럿 가능), `-`가 오답, `|` 뒤가 이유. 결과: `<p class="q" data-n="?">물음</p><div class="quiz"><button class="opt" [data-ok] data-why="이유">보기</button>…</div>`. 보기 순서는 물음 글로 만든 씨앗으로 섞는다(같은 파일은 늘 같은 순서, 정답이 늘 같은 번호가 되지 않게). 보기가 4개 넘으면 `data-cols="2"`.

**분류**
```
[분류] 양이온 | 음이온
- Na⁺ = 양이온 | 나트륨 원자가 전자 1개를 잃었다.
- Cl⁻ = 음이온 | 염소 원자가 전자 1개를 얻었다.
```
결과: `<div class="sort"><div class="bin" data-bin="b1"><h3>양이온</h3></div>…<span data-bin="b1" data-why="이유" data-hint="실마리">Na⁺</span>…</div>`. 실마리는 "칸 이름의 특징을 다시 보자."처럼 기본 문장.

**순서**
```
[순서] 탐구 순서대로 놓아 보자.
- 6홈 판에 용액을 넣는다. | 이유(없어도 됨)
```
결과: `<p class="q" data-n="?">물음</p><ol class="order"><li data-why="이유">…</li></ol>`(정답 순서로 쓰면 엔진이 섞는다).

### 2-5. 그림 자리와 배치
- `[그림 7-4] 설명` → `<figure class="fig"><img data-ppt="7-4" alt="설명"><figcaption>설명</figcaption></figure>`.
- 장에 그림과 글이 함께 있으면 두 칸: `<div class="lite-cols">`(글 칸 | 그림 칸 440px). 그림이 둘이면 그림 칸에 위아래로, 셋 이상이면 2열 격자.
- 그림만 있는 장은 가운데에 크게(높이 460px까지).
- CSS(필수, `lite.js`가 넣는다):
  - `.fig img[hidden] { display: none !important; }` — 엔진의 `.fig img{display:block}`이 `hidden`을 이겨 빈 그림 자리가 두 번 자리를 차지하는 문제를 막는다.
  - 그림 칸 안 `.fig img`와 `.ch-ppt-ph`는 `max-height: 300px; width: 100%; object-fit: contain`. 그림이 둘이면 각각 200px.

### 2-6. 장 나누기(넘침 막기)
엔진 CSS를 먼저 불러온 뒤, 화면 밖에 1280×720 장을 만들어 각 장의 내용 높이를 잰다. 제목 아래 쓸 수 있는 높이(약 470px, `data-sec` 없는 장은 510px)를 넘으면 뒤쪽 문단부터 새 장(`제목 (2)`)으로 옮긴다. 활동·익스플로라그램 덩어리는 나누지 않는다(그 앞 문장만 옮긴다). 잴 수 없으면 글자 수로 어림한다(본문 한 줄 약 34자, 48px).

## 3. 익스플로라그램 틀
모든 틀은 엔진 계산 상자(`.calc`)로 만든다. 스크립트가 필요 없고, 엔진이 0.6초 움직임·재생·점검을 맡는다. 틀은 `data-ai="모형"`을 붙이고 화면에 '(모형)'을 적는다. 식에 쓰는 변수 이름은 틀이 정한다(모델이 짓지 않는다). 엔진 함수 이름(`sign, min, max, round, log, e, x` 등)은 변수로 쓰지 않는다.

배치는 모두 `display:grid;grid-template-columns:600px 1fr;gap:28px;align-items:start`(그림 왼쪽, 손잡이·수치·문장 오른쪽). 높이는 제목 아래 470px 안.

### 3-1. `[끌려가기]` — 한쪽으로 끌려가는 움직임(전기장 속 이온, 낙하, 흐름)
```
[끌려가기]
왼쪽: (−)극
오른쪽: (+)극
켜기: 전원
고르기: 염화 나트륨 수용액 = Na⁺ 왼쪽 2, Cl⁻ 오른쪽 2
고르기: 질산 은 수용액 = Ag⁺ 왼쪽 2, NO₃⁻ 오른쪽 2
처음: 전원을 켜기 전에는 이온이 고르게 흩어져 있다.
끝: 양이온은 (−)극으로, 음이온은 (+)극으로 끌려간다.
```
- 입자 줄: `이름 방향 개수`. 방향은 `왼쪽 오른쪽 위 아래 그대로`. `고르기`가 하나면 단추를 만들지 않는다. `켜기`가 없으면 `data-const="on = 1"`.
- SVG 600×340: 바탕 상자, 왼쪽·오른쪽 끝에 막대(전극)와 이름(26px). 위·아래 방향이 있으면 위·아래 띠.
- 입자: 원(r 22) + 이름 글자(22px, 흰색, 가운데). 처음 자리는 가운데 영역(x 160~440, y 80~300)에 겹치지 않게 고르게, 끝 자리는 그 방향 끝(전극 앞 x 95 또는 505, 줄지어 쌓기). 색: 왼쪽으로 가는 입자 `#DC2626`, 오른쪽 `#2563EB`, 위 `#7C3AED`, 아래 `#B45309`, 그대로 `#6B7280`.
- 고르기마다 `<g data-show="sol == i">`로 입자 묶음. 원은 `data-attr="cx: x0 + (x1 - x0) * p; cy: y0 + (y1 - y0) * p"`, 글자는 `data-attr="x: …; y: … + 8"`.
- 계산: `data-let="p = on * t; nL = …; nR = …"` — `nL`은 지금 고른 묶음에서 왼쪽으로 가는 입자 수 × p를 반올림(`round`), `nR`도 같게. 그림에 그린 입자 수와 반드시 같은 수로 계산한다.
- 오른쪽 칸: 고르기 단추(`data-set="sol" data-value="i"`, 첫 단추 `aria-pressed="true"`), 켜기 단추 둘(`data-set="on" data-value="0"`「{켜기} 끔」 처음 눌림, `data-value="1"`「{켜기} 켬」), 시간 슬라이더 `<input type="range" name="t" min="0" max="1" step="0.1" value="0" data-play="5" aria-label="시간">`, `<p>{왼쪽} 쪽 <output data-expr="nL" data-unit="개"></output> · {오른쪽} 쪽 <output data-expr="nR" data-unit="개"></output> (모형)</p>`, 문장 `<p data-show="p == 0">{처음}</p>`, `<p data-show="p > 0 && p < 1">끌려가는 중이다.</p>`, `<p data-show="p == 1">{끝}</p>`.

### 3-2. `[고르기]` — 조건을 고르면 수치·그림·판정이 바뀐다
```
[고르기] 어떤 용액에 전기가 통할까?
값: 이온 수 | 개
그림: 전구
- 증류수 = 0 | 전기가 통하지 않는다. 이온이 없다.
- 이온 음료 = 6 | 전기가 통한다. 이온이 들어 있다.
```
- `값: 이름 | 단위`, `그림: 전구 | 막대 | 점`(없으면 막대). 항목 줄 `이름 = 수 | 문장`.
- 계산: `data-let="v = c == 1 ? 0 : c == 2 ? 6 : …; m = {최댓값, 0이면 1}"`.
- 그림(왼쪽 600px 칸):
  - 전구: SVG 600×340에 전선과 전지, 전구 원(r 70) `fill="#FACC15"` + `data-attr="fill-opacity: 0.08 + 0.92 * v / m"`, 빛살 8개 `data-attr="opacity: v > 0 ? v / m : 0"`. 아래 글자 "전구 밝기(모형)".
  - 막대: `<div class="bar" data-value="v" data-max="{m}">` + 값 글자.
  - 점: 점 m개를 격자로 그리고 i번째 점 `data-attr="opacity: v >= i ? 1 : 0.12"`.
- 오른쪽 칸: 물음(`p.q`), 단추(`data-set="c"`, 첫 단추 눌림), `<p>{이름} <output data-expr="v" data-unit="{단위}"></output> (모형)</p>`, 항목마다 `<p data-show="c == i">문장</p>`.

### 3-3. `[전자 이동]` — 원자가 전자를 잃거나 얻어 이온이 된다
```
[전자 이동]
- Li 리튬 3 잃음 1
- Na 나트륨 11 잃음 1
- Mg 마그네슘 12 잃음 2
- O 산소 8 얻음 2
- Cl 염소 17 얻음 1
```
- 줄: `기호 이름 원자번호 잃음|얻음 개수`. 이온식과 이름은 틀이 계산한다(모델이 쓰지 않는다).
  - 이온식: 기호 + (개수가 1이면 없음, 아니면 위첨자 숫자 ²³) + ⁺ 또는 ⁻. 예 Na⁺, Mg²⁺, O²⁻, Cl⁻.
  - 이름: 양이온은 `{이름} 이온`. 음이온은 이름이 '소'로 끝나면 '소'를 빼고 `화 이온`(산소→산화 이온, 염소→염화 이온), 아니면 `{이름}화 이온`(플루오린화 이온, 황화 이온).
- 구조: `.calc` 안에 `<div class="reveal" data-name="st" data-stops="시작|원자|이온">`(0단계 가림). 원자 고르기 단추 `data-set="el"`.
- 계산: `data-let="z = …; d = …(잃음은 −개수, 얻음은 +개수); ne = z + (st == 2 ? d : 0); q = z - ne"`. 표시 `<output data-expr="q > 0 ? '+' + q : q == 0 ? '0' : q">`.
- SVG(왼쪽, `.veil` 안): 원자핵 원(r 34, 글자 `+{z}`를 원자마다 `<g data-show="el == i">` 안에), 전자 껍질 점선 원(r 70, 110, 150). 원자번호 20 이하는 2, 8, 8, 2 규칙으로 껍질마다 전자 점(r 9, `#2563EB`)을 고르게 놓는다. 20 넘으면 가장 바깥 껍질 전자만 그리고 "안쪽 껍질은 생략(모형)"을 적는다.
  - 잃음: 가장 바깥 껍질 전자 k개가 `st == 2`에서 상자 오른쪽 밖(x 560, y 위아래로 벌림)으로 옮겨 가고 흐려진다(`data-attr="cx: …; cy: …; opacity: st == 2 ? 0.35 : 1"`).
  - 얻음: 상자 오른쪽(x 560)에 전자 k개가 흐리게 기다리다가(`st == 1`) `st == 2`에서 바깥 껍질 빈자리로 들어온다.
- 오른쪽 칸 `data-at="1"`: 단추 줄, `<p>양성자 <output data-expr="z" data-unit="개"></output> · 전자 <output data-expr="ne" data-unit="개"></output></p>`, `<p>전하의 합 <output …></output></p>`, `<p data-show="st == 1">양성자 수와 전자 수가 같아 전기적으로 중성이다.</p>`, `<p data-show="st == 2 && q > 0">전자를 잃어 (+)전하가 더 많아졌다. 양이온 <b><output data-expr="f"></output></b>, <output data-expr="nm"></output>이다.</p>`, 음이온도 같게. `f`, `nm`은 `data-let`에 원자마다 글자로 넣는다.

### 3-4. `[그래프]` — 값을 바꾸거나 시간을 흘리면 곡선과 점이 움직인다
```
[그래프] 시간이 지나면 빨대 속 물은 얼마나 올라갈까?
가로: t 0~10 0.5 | 시간 | 분 | 재생
세로: 0~9 | 올라간 높이 | 칸
식: 8 * c * (1 - exp(-t / 3))
고르기: c = 0.5 | 0.5 M, 1 | 1 M
문장: t == 0 → 「재생」을 누르고 지켜보자.
문장: t > 0 → 물이 튜브 안으로 들어와 빨대 속 물이 오른다.
```
- `가로: 변수 최소~최대 간격 | 이름 | 단위 | 재생(있으면 data-play="8")`. 변수 이름은 한 글자 영문(x 제외)만 받는다. 아니면 `a`로 바꾼다.
- `고르기: 변수 = 값 | 이름, 값 | 이름`(없어도 됨, 첫 값이 처음).
- 결과: `.calc`(`data-let="y = 식"`) 안에 `<figure class="plot" data-x="최소, 최대" data-y="세로 범위" data-height="320" data-xlabel="이름(단위)" data-ylabel="이름(단위)">`, `<i data-line="식에서 가로 변수를 x로 바꾼 것" data-x="최소, max(변수, 최소+0.01)">`(재생이면 지나온 곳까지만), `<i data-point="변수, y">`. 오른쪽 칸에 단추, 슬라이더(`name="변수"`), `<p>{세로 이름} <output data-expr="y" data-digits="1" data-unit="단위"></output> (모형)</p>`, `문장` 줄은 `<p data-show="조건">`.
- 식은 엔진 식 문법만(`+ - * / ^ ( )`, `exp ln log sqrt abs min max round`). `Math.`가 들어 있으면 지운다.

### 3-5. `[퍼지기]` — 제멋대로 움직이며 퍼진다(확산, 삼투, 기체)
```
[퍼지기]
막: 있음 | 세포 밖 | 세포 안
- 물 30 30 통과 파랑
- 설탕 20 5 막힘 주황
```
- `막: 있음|없음 | 왼쪽 이름 | 오른쪽 이름`. 줄 `이름 왼쪽수 오른쪽수 통과|막힘 색`(색: 파랑 빨강 주황 초록 보라 회색).
- 결과: `.calc` 안에 엔진 입자 상자 `figure.particles`(`data-membrane="0.5"` 또는 없음, `data-labels`, `data-height="300"`, 입자마다 `<i data-kind data-left data-right data-pass="1|0" data-color data-size="5|8" data-count="aL, aR">`). 오른쪽 칸에 종류마다 양쪽 개수 출력과 막대.
- 한쪽으로 끌려가는 움직임에는 쓰지 않는다(그건 `[끌려가기]`).

### 3-6. `[단계]` — 과정을 한 단계씩 연다
```
[단계] 염화 나트륨이 물에 녹으면?
- 고체 | Na⁺와 Cl⁻가 서로 붙어 있다. | 그림 19-9
- 물에 넣음 | 물 분자가 이온을 둘러싼다.
- 이온화 | 양이온과 음이온으로 나누어진다.
```
- 결과: `<div class="reveal" data-stops="시작|고체|물에 넣음|이온화">` 안에 단계마다 `<div data-only="i"><p>문장</p>(그림)</div>`. 이건 익스플로라그램이 아니라 과정 넘기기다.

## 4. 불러오기 순서(`lite.js`)
1. `DOMContentLoaded`를 기다린다.
2. `<body>`에 `section.slide`가 이미 있으면(편집 「HTML 저장」으로 저장한 파일) 펼치지 않고 엔진만 불러온다. 엔진 `<script>`가 이미 있으면 다시 넣지 않는다.
3. `<html>`에 `lang="ko"`, `data-deck`, `<body data-theme="ppt">`, 색 변수를 넣는다. `<meta name="viewport">`가 없으면 넣는다.
4. 엔진 CSS `<link>`와 라이트 CSS `<style id="lite-css">`를 넣고 CSS가 다 불릴 때까지 기다린다(5초 넘으면 그냥 진행).
5. 수업 글을 펼쳐 `section.slide`들을 `<body>`에 넣는다(수업 글 `<script>`는 그대로 둔다).
6. 장 나누기(2-6).
7. 엔진 JS `<script>`를 넣는다. 엔진이 곧바로 시작한다.
8. 오류가 나도 할 수 있는 데까지 펼치고, 문제 줄은 콘솔에 `[lite]`로 적는다.
