# v3 대규모 업데이트 — 공통 브리프 (2026-10-18)

여러 세션이 나눠 만든다. 이 파일이 화면·문구·색의 기준이다. 바꿀 일이 생기면 주 세션에 알린다.

## 이름과 핵심

- 상위 이름: **공명** (共鳴, Resonance). 한 줄: **교실의 진동수를 맞추다**. 바꾸지 않는다.
- 익스플로라그램(Exploragram)은 공명의 핵심 기능 넷 가운데 하나다. 저장소·엔진 이름(`exploragram`)은 그대로 둔다.
- 핵심 기능 넷(이 이름과 순서로 쓴다):
  1. **HTML 생성 및 편집** — 저장소 주소 한 줄과 PPT를 쓰던 AI에 주면, AI가 묻고(인터뷰) 설계표를 확인받아 수업 HTML을 만든다. 툴바 「편집」에서 바로 고쳐 저장한다. 자동 점검.
  2. **익스플로라그램** — 학생이 값을 바꾸면 그림·수치·그래프가 계산되어 함께 움직인다.
  3. **실시간 수업** — 「실시간」을 누르면 코드와 QR. 학생 기기가 교사 화면을 따라오고, 학생 답이 교사 화면에 이름 없이 모인다. 교사 판서도 학생 화면에 보인다.
  4. **전자칠판 기능** — 펜을 든 채 넘기고 단추를 누른다. 판서는 장마다·반마다 저장된다. 칠판, 레이저, 타이머, 발표자 뽑기 등.
- 만든 사람 표기: **Made by 엔의 생명과학**. 누르면 연락 팝업(연락 통로는 주 세션이 정해 알린다).

## 분위기 참고 (사용자가 준 레퍼런스: getdesign.md의 Planhat)

- 어두운 사진형 히어로 위 큰 제목, 가운데 정렬된 유리 알약 모양 상단 메뉴, 주황 알약 단추.
- 흰 바탕 구간: 왼쪽에 세로 탭 목록(고른 탭에 주황 세로 표시), 오른쪽에 제품 화면.
- 둥근 모서리(16~20px)의 벤토 카드 격자, 어두운 카드와 사진 카드를 섞는다. 여백을 넉넉히.
- 따뜻한 흙빛 톤. 사진 대신 우리는 실제 수업 화면(전자칠판·학생 기기)과 파동 그래픽을 쓴다.

## 한국어 화면 규칙 (/Volumes/T7/CLAUDE.md 요약 — 반드시 지킨다)

- `word-break: keep-all`, 넘침 방지 `overflow-wrap: anywhere`, 제목 `text-wrap: balance`, 설명 `text-wrap: pretty`. 강제 `<br>`·고정 폭·긴 `nowrap`으로 한 기기에만 맞추지 않는다.
- 320/375/768/1024px와 PC에서 직접 확인한다. 단어 중간 끊김, 한두 글자 줄, 잘린 단추, 가로 넘침을 본다.
- 본문 16px 이상, 누르는 것 44px 이상(주 단추 52px 이상).
- 사용자용 한국어 문구는 `~/.codex/skills/korean-humanize`의 윤문 게이트를 통과시킨다.
- **'만지다·만지는 수업' 표현은 쓰지 않는다.** 학생이 하는 일을 쓴다(값을 바꾼다, 끌어 옮긴다, 재생한다, 고른다).
- 움직임은 운영체제의 움직임 줄이기 설정을 따르지 않는다. 대신 건너뛰기·멈춤 단추를 둔다.

## 전환 참고 (사용자가 준 레퍼런스: zero.university — "트랜지션 너무 좋다")

- 스크롤에 묶인 고정 장면: 화면이 멈춘 채 안의 물건이 바뀐다(예: 책상 위 PPT 인쇄물이 말리고 접히며 전자칠판 수업으로 바뀜).
- 꽉 찬 장면이 스크롤을 내리면 둥근 모서리 카드로 줄어들며 빠진다. 반대로 카드가 꽉 찬 화면으로 펼쳐지며 들어온다.
- 문단의 단어가 스크롤에 따라 흐린 회색에서 진한 글자로 차례로 바뀐다.
- 아주 큰 글자가 화면을 가로질러 지나간다.
- 손글씨 메모와 손으로 그린 화살표를 곳곳에 붙인다. 우리에게는 **전자칠판 판서** 느낌이라 더 잘 맞는다.
- 라이브러리: GSAP 3.13.0 + ScrollTrigger 3.13.0, cdnjs에서 정확한 버전으로 불러온다.
  `https://cdnjs.cloudflare.com/ajax/libs/gsap/3.13.0/gsap.min.js`, `…/3.13.0/ScrollTrigger.min.js`.
- 작은 화면(768px 미만)에서는 고정 장면을 짧게 줄이고, 화면 오른쪽 아래에 「움직임 멈춤」 단추를 둔다.

## 고정할 주소 (이미 나간 링크·QR·제출 문서가 쓴다. 바꾸거나 지우지 않는다)

`/`(index.html), `/?join=코드`, `/?live=local`, `/lessons/<이름>.html`, `/examples/training.html`, `/examples/intro-story.html`, `/tour.html`, `/live-demo.html`.

- 학생은 대부분 처음 오는 사람이다. **수업 코드 입력 칸은 인트로가 도는 동안에도 헤더에서 바로 쓸 수 있어야 한다.** `?join=`으로 오면 인트로 없이 바로 입장한다.
- 입장 로직(`site/index.html`의 `join()`·`?join=`·`live=local` 처리, `live-config.js`)은 동작을 바꾸지 않고 옮긴다.

## 새 화면 파일

- 화면 1 `site/index.html`(인트로 → 엔딩), 화면 2 `site/explore.html`(살펴보기), 화면 3 `site/make.html`(제작하기).
- 에셋은 `site/assets/` 한 곳. 원본은 `site/assets/_src/`(저장소에 안 올림).

## 인트로 모듈 약속 (`site/assets/intro/`)

- `intro.js`가 `window.ResonanceIntro = { mount(el, { onEnd }) }`를 내놓는다. `mount`는 `{ skip(), destroy() }`를 돌려준다.
- 15초, 시간 기반 타임라인(같은 시각이면 같은 그림 — 프레임 캡처로 MP4를 만들 수 있게). 「건너뛰기」 단추 포함.
- 마지막 장면은 「공명」과 「교실의 진동수를 맞추다」가 놓인 정지 화면이다. 끝나면 `onEnd()`를 부르고 그 화면에 머문다. 엔딩 단추(살펴보기·제작하기)는 사이트가 그 위에 얹는다.
- 화면 위쪽 72px는 사이트의 고정 헤더가 덮는다. 중요한 그림을 거기 두지 않는다.

## 예시 수업 약속 (`examples/v3/`)

- 파일 이름은 ASCII 소문자·숫자·하이픈만, `v3-` 접두: `v3-elem-korean`, `v3-elem-pe`, `v3-elem-music`, `v3-elem-art`, `v3-mid-math`, `v3-mid-english`, `v3-mid-info`, `v3-mid-tech`, `v3-high-bio`, `v3-high-physics`, `v3-high-history`, `v3-high-econ` (+ `.html`).
- `<html data-deck>`도 같은 이름. 엔진은 지침 그대로 `@2` CDN 두 줄. 그림은 `examples/v3/media/<이름>/`.
- 학교급마다 `examples/v3/meta-<elem|mid|high>.json` 하나(세션끼리 같은 파일을 쓰지 않게):
  `[{ "slug", "level": "초등|중등|고등", "subject", "title", "question"(장면을 여는 물음 한 줄), "exploragrams": ["…"], "slides": 숫자, "model": "Claude Opus 5.5 · xhigh", "made": "2026-10-18" }]`

## 저장소 규칙

- 학생 실명·학교·전화·교과서 그림을 넣지 않는다. 외부 스크립트는 정확한 버전으로만.
- 여러 세션이 같은 폴더(`/Volumes/T7/Projects/PPT to HTML/exploragram`)에서 동시에 일한다. **맡은 파일만 고치고, 커밋·브랜치 전환은 하지 않는다.** 커밋은 주 세션이 모아서 한다.
