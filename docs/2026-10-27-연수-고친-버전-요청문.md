## 넣은 순서

'코드는 고치지 말고 먼저 보여 줘'로 끝나는 요청문(1-1, 1-3, 2-1)은 AI가 답만 하고 화면은 그대로 둔다.
답을 보고 고를 것을 고른 다음, 고치는 요청문을 넣었다.

### 1. 1-1 앱을 한 문장으로 (코드 그대로)

```
[단계] 1단계 전략
[문제] 첫 화면을 봐도 이 앱을 누가 어떤 상황에서 쓰는 것인지 알기 어렵습니다.
[원하는 결과] 코드는 고치지 말고, 현재 앱의 화면과 기능을 살펴본 뒤 이 앱을 누가 어떤 수업 상황에서 쓰는지 한 문장으로 정리해서 먼저 보여 줘.
[바꾸지 말 것] 학생이 수업 코드로 들어오는 입장 기능, 예시 수업과 AI별 비교 내용, 수업 화면의 다른 도구와 단축키
```

AI 답: 교사가 수업 PPT나 PDF를 쓰던 AI에 넣어 실시간 수업 HTML을 만들고, 수업 중에는 학생 기기가 교사 화면을 따라오게 하는 도구입니다.

이 답을 줄여 점검표 '만들기 전 질문' 1번에 '수업 PPT나 PDF를 넣으면 실시간 수업 HTML이 됩니다'라고 적었다. 그러면 1-2 요청문에 이 문장이 들어간다.

### 2. 1-3 부제 후보 (코드 그대로)

```
[단계] 1단계 전략
[문제] 앱 이름만 적혀 있어서 처음 보는 사람은 무슨 일을 하는 앱인지 알 수 없습니다.
[원하는 결과] 코드는 고치지 말고, 처음 보는 교사나 학생도 단번에 이해할 수 있도록 앱 이름 옆에 붙일 쉬운 부제 후보 3가지를 먼저 보여 줘.
[바꾸지 말 것] 학생이 수업 코드로 들어오는 입장 기능, 예시 수업과 AI별 비교 내용, 수업 화면의 다른 도구와 단축키
```

AI 답: ① PPT를 실시간 수업 HTML로 ② 쓰던 PPT로 만드는 실시간 수업 ③ AI로 만드는 실시간 수업 HTML

①을 골랐다. 이어서 직접 한 줄을 더 넣었다: "1번 부제를 앱 이름 옆에 넣어 줘."

### 3. 1-2 첫 화면 맨 위에 한 문장

```
[단계] 1단계 전략
[문제] 첫 화면에 이 앱을 왜 써야 하는지 알려 주는 핵심 소개 문장이 없습니다.
[원하는 결과] 첫 화면 맨 위 제목 바로 아래에 ‘수업 PPT나 PDF를 넣으면 실시간 수업 HTML이 됩니다’를 한눈에 들어오게 넣어 줘. 뜻이 모호한 홍보 문구나 긴 인사말은 지워 줘.
[바꾸지 말 것] 학생이 수업 코드로 들어오는 입장 기능, 예시 수업과 AI별 비교 내용, 수업 화면의 다른 도구와 단축키
```

### 4. 3-1 대문 화면 없애고 첫 작업부터

```
[단계] 3단계 구조
[문제] 첫 화면에 핵심 작업이 바로 나오지 않아서 사용자가 무엇부터 해야 할지 헤맵니다.
[원하는 결과] 앱을 열었을 때 거치는 불필요한 대문 화면을 없애고, 사용자가 가장 먼저 해야 하는 첫 번째 작업 화면이 바로 나오게 순서를 바꿔 줘.
[바꾸지 말 것] 학생이 수업 코드로 들어오는 입장 기능, 예시 수업과 AI별 비교 내용, 수업 화면의 다른 도구와 단축키
```

### 5. 2-1 핵심 기능과 부가 기능 나누기 (코드 그대로)

```
[단계] 2단계 범위
[문제] 핵심 기능과 부가 기능이 구분 없이 한꺼번에 나와 있어서 화면이 복잡합니다.
[원하는 결과] 코드는 고치지 말고, 현재 화면에 있는 기능들을 '꼭 있어야 하는 핵심 기능'과 '선택해서 쓰는 부가 기능'으로 나누어 목록으로 먼저 보여 줘.
[바꾸지 말 것] 학생이 수업 코드로 들어오는 입장 기능, 예시 수업과 AI별 비교 내용, 수업 화면의 다른 도구와 단축키
```

AI 답(제작하기 화면 기준):
- 핵심 기능: 지침 문장 복사, 쓰던 AI 열기, 수업 코드로 입장
- 부가 기능: 화면 가득한 사진 머리말과 꾸밈 목록, 예시 수업 둘러보기, AI별 결과 비교

이어서 직접 한 줄을 더 넣었다: "부가 기능 중 예시 수업과 AI별 비교는 내용은 그대로 두고 접어 줘. 사진 머리말은 지워 줘."

### 6. 2-2 긴 안내문 줄이기

```
[단계] 2단계 범위
[문제] 화면에 읽어야 할 설명글이 너무 길어서 사용자가 글을 읽지 않고 지나칩니다.
[원하는 결과] 화면에 있는 세 줄 이상의 긴 안내문을 모두 찾아 한 줄짜리 행동 안내로 줄여 줘. 읽지 않아도 아는 당연한 설명은 아예 지워 줘.
[바꾸지 말 것] 학생이 수업 코드로 들어오는 입장 기능, 예시 수업과 AI별 비교 내용, 수업 화면의 다른 도구와 단축키
```

[원하는 결과] 가장 자주 쓰는 핵심 기능 버튼을 아래 도구바에서 빼내어 화면 오른쪽 아래에 따로 떠 있는 플로팅 버튼으로 분리해 줘.

## 연수 화면 띄우는 법

수정 전은 공개 주소를 그대로 연다.

- 첫 화면: https://n-lifescience.github.io/resonance/
- 제작하기: https://n-lifescience.github.io/resonance/make.html
- 수업 화면: https://n-lifescience.github.io/resonance/lessons/sci-diffusion.html

수정 후는 이 브랜치에서 사이트를 묶어 노트북에서 띄운다.

```bash
cd "/Volumes/T7/Projects/PPT to HTML/exploragram" && git switch ux-fixed-1027 && node tools/build.mjs && node tools/site.mjs && python3 -m http.server 4191 --directory _site
```

- 첫 화면: http://localhost:4191/
- 제작하기: http://localhost:4191/make.html
- 수업 화면: http://localhost:4191/lessons/sci-diffusion.html?live=local (`?live=local`은 같은 PC 시험 모드라 실제 실시간 서버에 붙지 않는다)

첫 화면의 「문장 복사」를 누르면 공개 복사 횟수가 1 늘어난다. 시연 때 누를지 미리 정해 둔다.
