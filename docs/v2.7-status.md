# v2.7 현황 (2026-10-27, v2.7.1)

사용자 요청(10-26 저녁): 타이머가 다 되면 소리 알람이 울리게.

## 타이머 끝 소리 (`62-timer.js` Chime, `31-settings.js`)

- 장 안 타이머와 툴바 타이머가 끝나면(`Timer.tick`이 0에 닿을 때) 딩동댕(도6·솔#5·미5 근처 세 음)을 두 번 울린다. 약 3초. 소리 파일 없이 Web Audio로 만든다.
- 브라우저는 사람이 누른 뒤에만 소리를 내게 하므로 「시작」·「이어서」를 누를 때(`Timer.toggle`) 소리 장치를 깨워 둔다(`Chime.prime`). 툴바 타이머는 창의 시간 단추를 누를 때 시작하므로 같은 길로 깨워진다.
- ⚙ 설정 「화면과 소리」 묶음에 「타이머 끝 소리」(처음에는 켬)를 더했다. 묶음 이름 「화면」을 「화면과 소리」로 바꿨다.
- 실시간 학생 화면은 울리지 않는다. 학생 화면 오른쪽 아래의 남은 시간은 따로 그리고, 학생 기기에서 장 안 타이머를 눌러도 `Live.role === 'student'`면 울리지 않는다(학생 기기 30대가 한꺼번에 울리지 않게).

## 시험

- `parts-timer.test.html`(10): 시작을 누르면 소리 장치를 깨운다, 장 안 타이머와 툴바 타이머가 끝나면 한 번 울린다, ⚙에서 끄면 울리지 않는다, OfflineAudioContext로 렌더링해 딩동댕 두 번이 실제로 들리고(0.2 넘음) 4초 안에 끝나며 찌그러지지 않는다.
- `settings.test.html`: 기본값, 스위치 여덟 개, 묶음 이름을 고쳤다.
- 단위 106, 브라우저 43파일 통과. 고치기 전 엔진(v2.6.0)으로는 타이머 시험 4개가 실패한다.

## 확인 못 한 것

- 실제 스피커로 들어 보지 않았다(소리 크기, 교실에서 들리는지). 전자칠판 PC의 음소거·음량은 엔진이 바꾸지 못한다.
- 아이패드 사파리처럼 화면을 껐다 켜면 소리 장치를 멈추는 브라우저는, 다시 누르기 전까지 울리지 않을 수 있다.

## v2.7.1 (2026-10-27): 옛 브라우저 학생 화면의 판서 도구 (`86-live.css`, `24-ink.js`, `68-live.js`)

- 학생 화면에서 판서 도구를 숨기는 규칙이 `:is()`를 썼다. 크로뮴 88보다 오래된 학교 태블릿 브라우저는 이 규칙을 통째로 버려 툴바가 보였고, 펜을 고른 학생은 익스플로라그램 슬라이더를 움직이지 못했다(2026-10 수업).
- 숨김 규칙을 `:is()` 없이 풀어 썼다. 학생 역할이 되면 JS로도 판서 도구를 숨기고 도구를 손으로 둔다. 학생 화면에서는 `Tools.set`이 늘 손만 고른다.
- 단위 106, 브라우저 43파일 통과. 옛 브라우저를 흉내 내는 시험은 없고, 실제 학교 태블릿으로도 확인하지 못했다.
