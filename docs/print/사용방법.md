# 공명 사용 방법

공명은 교사가 쓰던 AI와 수업 자료로 전자칠판용 HTML 수업 파일을 만드는 도구입니다. 교사와 학생 모두 가입하지 않고 바로 쓸 수 있습니다. 학생은 실시간 수업에 들어갈 때 코드 6자리나 QR을 사용합니다.

## 1. AI와 함께 수업 만들기

공명 사이트(엔의생명과학.한국/공명)의 「제작하기」에서 세 단계를 차례로 따라 하면 됩니다.

### ① 프롬프트 복사하기

아래 문장을 복사합니다. 쓰던 AI에게 공명 지침대로 수업을 만들어 달라는 부탁입니다.

`https://github.com/N-lifescience/resonance 지침대로 이 자료를 수업 HTML로 바꿔줘`

### ② 쓰던 AI에 수업 자료 올리고 문장 붙여 넣기

ChatGPT나 Gemini, Claude 가운데 쓰던 AI를 엽니다. 「제작하기」의 단추로 웹이나 데스크톱 앱을 바로 열 수 있고, 로그인은 각자 계정으로 합니다. 대화창에 수업 자료를 올리고 복사한 문장을 붙여 넣어 보냅니다. 수업 자료는 PPT뿐 아니라 교사용 교과서 PDF도 됩니다.

AI가 저장소 주소를 읽지 못하면 지침 파일을 내려받아 수업 자료와 함께 올립니다. 수업 자료에 교과서나 출판사 그림이 들어 있다면 완성 파일은 수업에만 쓰고 인터넷에는 공개하지 마세요.

### ③ 질문에 답하고 HTML 생성하기

AI는 교과와 학년, 차시를 먼저 확인합니다. 그다음 수업 자료에서 학생이 헷갈릴 만한 장면을 골라 묻고 넣을 기능 목록을 보여 줍니다. 익스플로라그램 장면과 확인 문제, 전자칠판 도구, 실시간 활동 가운데 필요한 것을 고르면 됩니다.

원하는 기능이 목록에 없으면 설문으로 제안할 수 있습니다. AI는 없는 기능을 있는 것처럼 만들지 않고 비슷한 기능을 안내합니다. 제안할 내용은 선생님이 직접 확인하고 설문에 옮겨 적습니다. AI가 자동으로 보내지는 않습니다.

AI가 정리한 설계표에서 개념과 학생이 어려워하는 점, 바꿀 값, 장면의 축과 사용할 부품을 확인합니다. 바꿀 점이 있으면 파일을 만들기 전에 알려 주세요. 설계표를 확인하면 AI가 HTML 파일 하나를 만듭니다. 내려받은 파일을 더블클릭하면 수업이 열립니다. 그림 자리가 비어 있으면 원본 PPT를 화면에 끌어다 놓고 설정의 「그림 넣어 저장」을 누르세요.

## 2. 전자칠판에서 수업하기

### 펜을 든 채로 넘기기

펜이나 형광펜을 고른 상태에서도 「이전」과 「다음」을 누를 수 있습니다. 활동 단추와 슬라이더도 그대로 쓸 수 있어 손 모드와 펜 모드를 오갈 필요가 없습니다. 판서는 장별, 반별로 저장되고 브라우저를 닫아도 남습니다.

### 칠판과 반별 판서

도구 막대에서 「칠판」을 열어 빈 칠판에 쓰고, 다 쓰면 원래 장 화면으로 돌아옵니다. 판서는 반마다 나뉘어 저장됩니다. 학교 PC를 다시 켤 때 자료가 지워진다면 반 메뉴의 「판서 백업 파일로 저장」을 쓰세요. 판서를 넣어 인쇄할 수도 있습니다.

### 전자칠판 도구

수업에 따라 레이저와 화면 가리기, 타이머, 발표자 뽑기, 모둠 점수판, 투표와 체크리스트를 씁니다. 설정의 「기능 켜고 끄기」에서 판서와 칠판, 실시간 수업 기능을 각각 켜고 끌 수 있습니다. 학교 전자칠판 자체 펜을 쓰려면 공명의 판서를 끄세요. 판서를 꺼도 편집 기능은 계속 쓸 수 있습니다.

### 편집 모드

도구 막대에서 「편집」을 눌러 글이나 상자, 그림, 도형을 고릅니다. 내용과 크기, 색, 위치를 고친 뒤 HTML 파일로 저장합니다. AI에게 다시 부탁하지 않고 바로 고칠 수 있습니다.

### 자동 점검

처음 파일을 열면 자동 점검이 실행되고, 문제가 있으면 도구 막대에 「점검」 표시가 나옵니다. 전자칠판에서는 설정의 「자동 점검」에서 열 수 있습니다. 점검 창의 「AI에게 보낼 말 복사」를 눌러 복사한 글을 AI 대화창에 붙여 넣으면 문제를 고칠 수 있습니다.

## 3. 실시간 수업

### 코드나 QR로 참여하기

교사 화면에서 「실시간」을 누르면 코드 6자리와 QR이 나옵니다. 학생은 QR을 찍거나 공명 사이트 위쪽의 「수업 코드」에 코드를 넣어 들어옵니다. 학생 기기는 교사 화면의 장을 따라갑니다. 교사가 허용한 범위에서 앞 장도 볼 수 있고, 「선생님 화면으로」를 누르면 교사가 보고 있는 장으로 돌아옵니다.

학생은 익스플로라그램 값을 직접 바꾸고 퀴즈와 투표, 단답 활동에 답을 보낼 수 있습니다. 교사는 「학생 보기」에서 학생 값과 답의 분포를 확인합니다. 슬라이더 값은 막대를 눌러 칠판 그림에 띄울 수 있습니다.

교사가 쓰는 판서와 칠판은 학생 화면에도 보입니다. 학생은 판서를 쓰거나 지울 수 없습니다. 실시간 창이나 설정에서 학생 화면의 판서 보이기를 끌 수 있고, 레이저는 학생 화면에 나타나지 않습니다.

학생 값과 응답은 이름 없이 수업 중 교사 화면에만 모이고, 창을 닫으면 모두 사라집니다. 학생 이름은 입력받지 않습니다.

### 학생용 파일이 필요한 경우

실시간 수업에는 인터넷 연결이 필요합니다. 수업 파일이 웹 주소로 열려 있으면 학생이 QR로 바로 들어올 수 있습니다. 웹 주소가 없는 파일이면 「실시간」 창에서 「학생용 파일 저장」을 눌러 파일을 받습니다. 받은 파일을 웨일 클래스에 올리면 학생이 파일을 열고 코드로 참여할 수 있습니다. 수업을 끝내면 실시간 창에서 수업을 종료하세요.
