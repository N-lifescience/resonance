# 공명 사용 방법

공명은 교사가 쓰던 AI와 수업 PPT로 전자칠판용 HTML 수업 파일을 만드는 도구예요. 교사와 학생 모두 가입하지 않고 바로 쓸 수 있어요. 학생은 실시간 수업에 들어갈 때 코드 6자리나 QR을 사용해요.

## 1. AI와 함께 수업 만들기

### 지침 주소와 PPT 보내기

수업 PPT를 ChatGPT나 Gemini, Claude처럼 쓰던 AI에 올리고 아래 문장을 보내세요.

`https://github.com/N-lifescience/resonance 지침대로 이 PPT를 수업 HTML로 바꿔줘`

AI가 저장소 주소를 읽지 못하면 지침 파일을 내려받아 PPT와 함께 올리세요. PPT에 교과서나 출판사 그림이 들어 있다면 완성 파일은 수업에만 쓰세요. 인터넷에는 공개하지 마세요.

### 인터뷰에서 수업 기능 고르기

AI는 교과와 학년, 차시를 먼저 확인해요. 그다음 PPT에서 학생이 헷갈릴 만한 장면을 골라 물어요. 학생이 어떤 값을 바꾸거나 무엇을 확인하면 좋을지 함께 살펴보세요. 익스플로라그램 장면과 확인 문제, 전자칠판 도구, 실시간 활동 중 필요한 것을 고르면 돼요.

원하는 기능이 목록에 없어도 설문에 제안할 수 있어요. AI는 없는 기능을 있는 것처럼 만들지 않고 비슷한 기능을 안내해요. 제안할 내용은 선생님이 직접 확인하고 설문에 옮겨 적어 주세요. AI가 자동으로 보내지는 않아요.

### 설계표 확인하고 파일 받기

AI가 정리한 설계표에서 개념과 학생이 어려워하는 점, 바꿀 값을 확인하세요. 장면의 축과 사용할 부품도 함께 살펴보세요. 빠진 내용이나 바꿀 점이 있으면 파일을 만들기 전에 알려 주세요.

설계표를 확인하면 AI가 HTML 파일 하나를 만들어요. 파일을 열어 바로 수업하세요. 그림 자리가 비어 있으면 원본 PPT를 화면에 끌어다 놓으세요. 그다음 설정의 「그림 넣어 저장」을 누르면 돼요.

## 2. 전자칠판에서 수업하기

### 펜을 든 채로 넘기기

펜이나 형광펜을 고른 상태에서도 「이전」과 「다음」을 누를 수 있어요. 활동 단추와 슬라이더도 그대로 쓸 수 있어요. 손 모드와 펜 모드를 계속 오갈 필요가 없어요. 판서는 장별, 반별로 저장돼요. 브라우저를 닫아도 판서가 남아요.

### 칠판과 반별 판서

도구 막대에서 「칠판」을 열어 빈 칠판에 글씨를 쓰세요. 다 쓴 뒤에는 원래 장 화면으로 돌아올 수 있어요. 판서는 반마다 나뉘어 저장돼요. 학교 PC를 다시 켤 때 자료가 지워진다면 반 메뉴의 「판서 백업 파일로 저장」을 쓰세요. 판서를 넣어 인쇄할 수도 있어요.

### 전자칠판 도구

수업에 따라 레이저와 화면 가리기, 타이머, 발표자 뽑기, 모둠 점수판, 투표와 체크리스트를 써 보세요. 설정의 「기능 켜고 끄기」에서 판서와 칠판, 실시간 수업 기능을 각각 켜고 끌 수 있어요. 학교 전자칠판 자체 펜을 쓰려면 공명의 판서를 꺼 주세요. 판서를 꺼도 편집 기능은 계속 쓸 수 있어요.

### 편집 모드

도구 막대에서 「편집」을 눌러 글이나 상자, 그림, 도형을 고르세요. 내용과 크기, 색, 위치를 고친 뒤 HTML 파일로 저장하면 돼요. AI에게 다시 부탁하지 않고 수업에 맞게 바로 고칠 수 있어요.

### 자동 점검

처음 파일을 열면 자동 점검이 실행돼요. 문제가 있으면 도구 막대에 「점검」 표시가 나와요. 전자칠판에서는 설정의 「자동 점검」에서 열 수 있어요. 점검 창에서 「AI에게 보낼 말 복사」를 누르세요. 복사한 글을 AI 대화창에 붙여 넣으면 문제를 고칠 수 있어요.

## 3. 실시간 수업

### 코드나 QR로 참여하기

교사 화면에서 「실시간」을 누르면 코드 6자리와 QR이 나와요. 학생은 QR을 찍거나 공명 사이트에서 코드를 입력해 들어와요. 학생 기기는 교사 화면의 장을 따라가요. 교사가 허용한 범위에서 앞 장도 볼 수 있어요. 「선생님 화면으로」를 누르면 교사가 보고 있는 장으로 돌아와요.

학생은 익스플로라그램 값을 직접 바꿀 수 있어요. 퀴즈와 투표, 단답 활동에도 답을 보낼 수 있어요. 교사는 「학생 보기」에서 학생 값과 답의 분포를 확인해요. 슬라이더 값은 막대를 눌러 칠판 그림에 띄울 수 있어요. 퀴즈와 투표 응답도 교사 화면에 모여요.

교사가 쓰는 판서와 칠판은 학생 화면에도 보여요. 학생은 판서를 쓰거나 지울 수 없어요. 실시간 창이나 설정에서 학생 화면의 판서 보이기를 끌 수 있어요. 레이저는 학생 화면에 나타나지 않아요.

학생 값과 응답은 이름 없이 수업 중 교사 화면에만 모여요. 창을 닫으면 모두 사라져요. 학생 이름은 입력받지 않아요.

### 학생용 파일이 필요한 경우

실시간 수업에는 인터넷 연결이 필요해요. 수업 파일이 웹 주소로 열려 있으면 학생이 QR로 바로 들어올 수 있어요. 웹 주소가 없는 파일이면 「실시간」 창에서 「학생용 파일 저장」을 눌러 파일을 받으세요. 받은 파일을 웨일 클래스에 올리면 학생이 파일을 열고 코드로 참여할 수 있어요.

학생은 자기 화면에서 지난 장을 다시 볼 수 있어요. 언제든 교사가 보고 있는 화면으로 쉽게 돌아올 수도 있어요. 수업을 끝내면 실시간 창에서 수업을 종료하세요.
