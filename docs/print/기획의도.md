# 공명 기획의도

## 1. 기획 의도

교사는 이미 수업 PPT를 갖고 있다. AI로 자료 형식을 바꾸는 일은 쉬워졌지만 교실에서 바로 쓰려면 손이 더 간다. 전자칠판에 판서하고 학생 기기를 연결해야 한다. AI가 만든 자료도 직접 고쳐야 한다.

공명은 교사가 쓰던 AI와 PPT로 학생이 원리를 스스로 찾아보는 수업을 만든다. 만든 수업은 교실 전자칠판과 학생 기기에서 바로 쓴다. 한 장의 PPT를 학생이 값을 바꿔 보는 장면으로 바꾼다. 교사와 학생은 같은 화면에서 수업을 이어 간다.

## 2. 해결하려는 문제

| # | 문제 | 교실에서 겪는 일 |
|---|---|---|
| 1 | 만들기 어렵고 결과가 일정하지 않다 | 같은 부탁에도 AI마다 화면과 활동이 다르게 나온다. 판서나 넘기기 같은 기본 기능이 빠지기도 한다. 고칠 곳이 생기면 AI에 다시 부탁해야 한다. |
| 2 | PPT가 정지된 그림에 머문다 | 확산이나 수요와 공급처럼 값에 따라 달라지는 개념도 그림 몇 장으로 보여 준다. 학생이 변수를 바꿔 결과를 살펴보기 어렵다. |
| 3 | 전자칠판 판서가 불편하고 남지 않는다 | 펜과 넘기기 모드를 오가야 한다. 장을 넘기거나 파일을 닫으면 판서가 사라질 수 있다. 반마다 판서를 따로 남기기도 어렵다. |
| 4 | 교사 화면과 학생 기기가 따로 논다 | 학생은 칠판을 바라보는 데 그친다. 교사는 반 전체의 생각이 어디에 모였는지 확인하기 어렵다. |

## 3. 핵심 기능

### ① HTML 생성 및 편집 — 만들기 문제 해결

교사는 쓰던 AI에 저장소 지침 주소 한 줄과 PPT를 건넨다. AI가 교과와 차시, 학생이 헷갈리는 지점, 원하는 활동을 묻고 설계표를 보여 준다. 교사가 설계표를 확인하면 AI가 수업 HTML 파일 하나를 만든다.

완성된 파일은 툴바의 「편집」에서 글과 상자, 그림, 도형을 고쳐 저장할 수 있다. 자동 점검은 화면 넘침과 작은 글자, 부품 오류를 찾는다. 찾은 문제는 교사가 AI에 다시 전달할 수 있는 문장으로 정리한다.

### ② 익스플로라그램 — 정지된 자료 문제 해결

학생이 값을 바꾸거나 그래프의 점을 끌어 옮긴다. 그러면 그림과 수치, 그래프가 함께 계산되어 바뀐다. 시간에 따라 변하는 실험과 공간에 따른 차이, 대상이 퍼지거나 전달되는 장면을 다룬다.

계산 상자와 그래프, 입자 상자, 재생 단추, 지도와 연표를 쓸 수 있다. 즉시 확인 문제와 분류, 순서, 라벨, 단답 활동도 넣을 수 있다. 교과와 PPT 장면에 맞는 부품을 골라 학생이 원리를 살펴보게 한다.

### ③ 실시간 수업 — 분리된 화면 문제 해결

교사가 툴바에서 「실시간」을 누르면 코드 6자리와 QR이 나온다. 학생 기기는 교사 화면의 장을 따라간다. 학생은 슬라이더 값과 퀴즈 응답, 투표와 단답을 보낼 수 있다. 응답은 이름 없이 교사 화면에 모인다.

교사가 쓴 판서와 칠판도 학생 화면에 보인다. 학생 값과 응답은 수업 중 교사 화면에만 남고 창을 닫으면 사라진다. 이름은 받지 않는다.

### ④ 전자칠판 기능 — 판서 문제 해결

펜을 든 채로 장을 넘기고 활동 단추와 슬라이더를 쓸 수 있다. 교사는 펜 모드와 조작 모드를 오갈 필요가 없다. 판서는 장별, 반별로 저장된다.

빈 칠판과 레이저, 타이머, 발표자 뽑기, 모둠 점수판, 투표와 체크리스트를 함께 쓴다. 학교 전자칠판의 펜을 쓰고 싶다면 설정에서 공명의 판서 기능을 끌 수 있다.

## 4. 사용하는 흐름

교사는 쓰던 AI에 저장소 지침 주소 한 줄과 수업 PPT를 보낸다. AI는 PPT를 살펴보고 교과와 차시, 학생이 어려워하는 장면, 원하는 활동을 묻는다. 교사가 답하면 AI는 익스플로라그램 축과 부품, 움직이는 대상을 정리한 설계표를 보여 준다.

교사가 설계표를 확인하면 AI가 HTML 파일 하나를 만든다. 교사는 파일을 열어 수업한다. 고칠 곳이 있으면 「편집」에서 글과 그림을 바로 바꾼다. 자동 점검으로 화면 넘침과 작은 글자, 부품 오류를 확인한다.

## 5. 기대 효과

교사는 새 도구를 따로 익히지 않고 쓰던 AI와 PPT로 수업 자료를 만든다. 결과를 파일 안에서 직접 고친다. 전자칠판 판서와 학생 기기 연결도 같은 수업 화면에서 이어 간다.

학생은 설명을 듣는 데서 그치지 않고 직접 값을 바꾼다. 그림과 그래프의 변화를 살펴보며 자신의 답을 보낸다. 교사는 반 전체의 응답을 함께 보며 다음 설명과 활동을 정할 수 있다.
