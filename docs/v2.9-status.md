# v2.9 현황 (2026-11-26, v2.9.0)

사용자 요청: 칠판 판서 도구에서 양옆 가장자리 화살표 탭 자리에 왼쪽 ‹(이전), 오른쪽 ›(다음) 넘김 단추를 두고, 아래 단추(툴바)는 없애고, 판서 도구는 처음부터 떠 있게.

## 가장자리 탭은 넘기기 (`30-toolbar.js` `buildEdges`, `30-toolbar.css`)

- 화면 왼쪽 끝 가운데 ‹ = 이전 장, 오른쪽 끝 가운데 › = 다음 장. 28×80px 반원 탭, 흰색 안쪽과 검정 바깥쪽 이중선.
- 펜을 든 채로도 넘기고, 칠판 모드에서는 칠판을 넘긴다(`Nav.override`). Enter·Space는 장 넘기기 단축키로 새지 않는다.
- 인쇄, 편집 모드, 실시간 학생 화면에서는 숨는다(`50-print`, `85-edit`, `86-live`, `68-live`의 옛 브라우저 대비 숨김).

## 판서 도구는 떠 있는 단추 하나 (`buildHud`)

- 양옆 HUD 두 개를 떠 있는 동그란 단추(52px) 하나로 합쳤다. 처음 자리는 왼쪽 아래(화면 비율 x 0.03, y 0.8).
- 누르면 손·펜·형광펜·지우개·레이저, 되돌리기, 슬라이드|칠판, 「더보기」가 화면 가운데 쪽으로 열린다. 끌면 어디든 옮기고, 화면 끝에 놓아도 가장자리에 붙지 않는다(끝은 넘기기 자리). 두 번 톡 전환은 없앴다.
- 자리는 `Store('toolbar').float`에 저장한다. 예전 저장값(dock, collapsed, 양옆 hud)은 읽지 않는다.

## 아래 툴바는 「더보기」 안으로

- `.ch-toolbar`를 화면 아래에 깔지 않고(무대 여백 `--ch-reserve-*` 모두 0) 도구판 옆에 4칸 격자로 펼친다. 색, 이 장 지우기, 칠판 추가·삭제·바탕, 반, 편집, 타이머, 목차, 전체 화면, 설정이 들어 있다. 도구판에 있는 판서 도구·되돌리기·슬라이드|칠판은 격자에서 뺀다. 위치·접기 단추와 「도구」 손잡이는 없앴다.
- 더보기에서 바로 일하는 단추를 누르거나, 팝오버(색, 바탕, 반, 타이머, 설정)에서 고르면 도구판이 닫혀 화면이 빈다.
- 480px 이하에서는 더보기를 펼치면 도구판은 「더보기」 단추만 남기고 격자는 3칸이다. 옆으로 넘치면 화면 안으로 민다(`--dx`).
- 판서를 끈 기기(⚙ 기능 켜고 끄기)에서도 떠 있는 단추와 「더보기」는 남아 설정을 다시 켤 수 있다.

## 「점검 N」 알림 (`42-audit.js`, `45-audit.css`)

- 툴바가 더보기 안에 숨어 보이지 않으므로, 떠 있는 판서 도구 단추 위에 노란 알약으로 붙인다. 단추가 화면 위쪽이면 아래에, 오른쪽 반이면 오른쪽 끝에 맞춘다.

## 시험

- 단위 113, 브라우저 45파일, 실제 입력 데모 3해상도, 문서 점검 통과. `toolbar.test.html`의 위치·접기·양옆 HUD 시험을 가장자리 넘기기, 떠 있는 단추, 더보기, 끌기 시험으로 바꿨다. `run-demo.mjs`는 도구판·더보기를 실제 마우스로 열어 누르고, 툴바 위치 대신 떠 있는 단추를 끌어 새로 고침 뒤 자리를 확인한다.
- 헤드리스 크롬 320, 375, 768, 1024, 1280, 1920px에서 닫힘, 도구판, 더보기 화면을 찍어 화면 안에 들어오는지 쟀다.

## 확인 못 한 것

- 실제 전자칠판에서 가장자리 탭과 떠 있는 단추의 크기와 자리, 손가락으로 끌기.
- `site/` 소개 그림(`sci-after-live.webp`)은 아직 아래 툴바가 보이는 옛 화면이다.
