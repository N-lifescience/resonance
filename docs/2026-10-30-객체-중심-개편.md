# 공명 사이트 객체 중심 개편 (2026-10-30)

- 브랜치: `ux-object-1030` (main `e593e68`에서 갈라져 `ux-fixed-1027`을 합친 뒤 고쳤다)
- 고친 사람: Claude Code(Claude Opus 5.5)
- 공개 사이트와 CDN 엔진(`@2`)은 그대로다. main에 합쳐 올려야 Pages가 바뀌고, 엔진은 새 `v2.*` 태그를 달아야 수업 파일에 반영된다.

## 왜 바꿨나

점검해 보니 공명 사이트는 할 일(태스크) 중심이었다. 메뉴가 「살펴보기」「제작하기」 같은 동사였고, 쪽마다 단계 설명과 단추가 먼저 나왔다. 실제 결과물은 깊숙이 있었다.

- 첫 화면: 15초 인트로가 화면을 차지했다. 무엇을 하는 도구인지는 바닥글 한 줄에만 있었다.
- 예시 수업 12개: 「제작하기」 맨 아래, PC 폭(1280px)에서 위에서 2,933px 아래에 있었다. 바꾼 뒤에는 첫 화면 786px 자리에서 시작한다.
- 강사 카드: Gemini 키 입력이 있는 양식이 먼저 나왔다. 보관함(카드)은 그 아래였다.

객체 중심(인스타그램처럼 결과물을 먼저 보여 주고, 결과물을 눌러 할 일을 고르는 방식)으로 바꿨다. 할 일은 「＋ 만들기」 하나로 모았다.

## 바뀐 것

| 쪽 | 바꾸기 전 | 바꾼 뒤 |
|---|---|---|
| 메뉴 | 살펴보기 / 제작하기 / 강사 카드 | 수업 / 기능 / ＋만들기 / 강사 카드. 아이콘을 붙였고, 좁은 화면(767px 이하)에서는 아래 탭 막대다 |
| 첫 화면 | 인트로 애니메이션, 단추 둘 | 한 문장, 바꾸기 전후 그림, 「내 PPT로 만들기」, 기능 영상 넷(스토리), 예시 수업 피드(학교급 고르기), 강사 카드 소개 |
| 예시 수업 | 제작하기 아래 가로 레일 | 첫 화면 피드. 누르면 미리 보기 창에서 바로 움직여 보고, 「새 탭에서 크게 열기」「내 PPT로 만들기」로 이어진다 |
| 만들기 | 제작하기 쪽의 세 단계 | 어느 쪽에서나 여는 만들기 창. AI 단추를 누르면 부탁 문장이 복사되고 AI가 열린다. 자세한 방법과 AI별 추천 설정은 그대로 `make.html` |
| 기능 | 화면 가득한 사진 머리말 | 제목과 한 줄. 기능별 영상과 체험은 그대로다 |
| 강사 카드 | 4단계 설명, 양식, 보관함, 대본 묶음, 백업 순서 | 보관함 먼저. 「새 카드」가 카드 만들기 창을 열고, 카드마다 「영상 더 넣기」가 있다. 카드가 없을 때는 예시 그림과 「첫 카드 만들기」. 백업과 안내는 접었다 |
| 인트로 | 첫 화면 자동 재생 | 바닥글 「공명 인트로 보기」(`assets/intro/intro.html`) |

## 지킨 것

- 학생 입장: 첫 화면의 수업 코드 창과 `?join=코드` 주소를 그대로 둔다(수업 QR이 가리킨다). 강사 카드 쪽은 CSP 때문에 입장 스크립트를 싣지 않고 첫 화면 입장 창(`./#join-h`)으로 보낸다.
- 예시 수업과 AI별 비교 내용, `make.html#lessons`, `#comparison` 주소.
- 강사 카드의 저장 방식, 백업, 카드 파일 형식(`cards.js`의 계산 함수는 그대로, 화면 연결만 바꿨다).
- 바깥 자료는 `textContent`로만 넣는다. `innerHTML`을 쓰지 않는다.
