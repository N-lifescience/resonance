# 정렬 알고리즘 — 비교와 교환 횟수로 견주기

- 교과·학년: 중학교 3학년 정보
- 단원: 알고리즘 — 정렬 (1차시)
- 준비: 전자칠판, 숫자 카드(모둠별 8장), 학생 기기(실시간 수업을 쓸 때)

## 학습 목표

1. 선택 정렬, 버블 정렬, 삽입 정렬이 자료를 정렬하는 과정을 설명할 수 있다.
2. 비교 횟수와 교환 횟수로 정렬 알고리즘의 효율을 견줄 수 있다.

## 수업 흐름 (45분)

| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 5분 | 숫자 카드 8장을 작은 수부터 늘어놓는다. 어떤 순서로 옮겼는지, 몇 번 견주었는지 말해 본다. |
| 전개 1 | 7분 | 정렬, 비교, 교환의 뜻. 세 정렬의 생각: 선택(가장 작은 값을 골라 앞으로), 버블(이웃끼리 견주어 큰 값을 뒤로), 삽입(하나씩 꺼내 앞쪽 정렬된 곳에 끼워 넣기). |
| 전개 2 | 10분 | 같은 자료 8개를 세 정렬로 한 단계씩 재생한다. 단계마다 무엇과 무엇을 견주고 언제 자리를 바꾸는지, 비교와 교환 횟수가 어떻게 쌓이는지 본다. |
| 전개 3 | 8분 | 무작위, 거의 정렬된, 거꾸로 놓인 자료로 세 정렬을 동시에 출발시킨다. 비교 한 번을 시간 한 칸으로 보고 누가 먼저 끝나는지 본다. |
| 전개 4 | 8분 | 자료 수를 5개에서 40개까지 늘리며 비교 횟수 그래프를 그린다. 자료가 2배가 되면 비교 횟수가 얼마나 느는지 말한다. |
| 정리 | 7분 | 확인 문제와 정리 |

## 핵심 내용

- 정렬: 자료를 정해진 순서(작은 수부터 등)로 늘어놓는 것.
- 비교: 두 값의 크기를 견주는 것. 교환: 두 값의 자리를 바꾸는 것.
- 선택 정렬: 정렬되지 않은 부분에서 가장 작은 값을 찾아 그 부분의 맨 앞 값과 바꾼다. 비교 횟수는 자료 모양과 상관없이 n(n−1)/2이다. 교환은 많아야 n−1번이다.
- 버블 정렬: 이웃한 두 값을 견주어 앞의 값이 크면 바꾼다. 한 바퀴를 돌면 가장 큰 값이 맨 뒤에 자리 잡는다. 이 수업에서는 바퀴마다 끝까지 견주는 기본형을 쓰므로 비교 횟수는 n(n−1)/2이다.
- 삽입 정렬: 두 번째 값부터 하나씩 꺼내 앞쪽 정렬된 부분의 알맞은 자리에 끼운다. 이 수업에서는 앞의 값과 한 칸씩 바꾸며 끼운다. 거의 정렬된 자료에서 비교 횟수가 크게 준다.
- 자료 수가 2배가 되면 n(n−1)/2는 약 4배가 된다.

## 확인 문제

1. [5, 3, 8, 1]을 버블 정렬로 한 바퀴 돌린 뒤의 배열 — [3, 5, 1, 8]
2. 여섯 가지 설명을 선택, 버블, 삽입 정렬로 나눈다.
3. 자료 10개를 선택 정렬할 때의 비교 횟수 — 45번
