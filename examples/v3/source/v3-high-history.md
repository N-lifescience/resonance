# 4~6세기 삼국의 영토 변화 (고1 한국사, 1차시 50분)

교사의 PPT를 대신하는 수업안이다. 교과서 문장과 지도를 쓰지 않고 새로 썼다. 지도는 경도·위도 점으로 직접 그린 단순한 그림이다.

## 단원과 목표

- 단원: 고대 국가의 발전 — 삼국의 영토 확장과 한강 유역
- 목표
  1. 4~6세기 삼국의 영토 변화를 시기 순서대로 설명한다.
  2. 삼국이 한강 유역을 두고 다툰 까닭을 말한다.

## 흐름

| 단계 | 시간 | 내용 |
|---|---|---|
| 생각 열기 | 5분 | 한강 유역의 주인은 세 번 바뀌었다. 한강 유역을 차지하면 무엇이 좋았을까? |
| 연표 | 7분 | 313 낙랑군 축출, 371 평양성 공격, 400 신라 구원, 427 평양 천도, 433 나제 동맹, 475 한성 함락·웅진 천도, 532 금관가야 병합, 538 사비 천도, 551 한강 유역 회복, 553 신라의 한강 하류 차지, 554 관산성 전투, 562 대가야 정복 |
| 영토 지도 | 15분 | 4세기 후반(백제 근초고왕), 5세기 후반(고구려 장수왕), 6세기 중반(551년 나제 동맹), 6세기 후반(신라 진흥왕)의 영토를 차례로 연다. 수도 이동, 한강의 주인, 땅 넓이 비율의 변화를 본다 |
| 전성기의 왕 | 5분 | 근초고왕, 광개토 대왕·장수왕, 진흥왕 정리 |
| 한강 유역의 가치 | 10분 | 경주 앞바다, 당항성, 대동강 하구에서 산둥 반도까지 뱃길 길이를 견준다. 한강 하류를 얻은 신라는 서해를 건너 중국과 직접 오갈 수 있게 되었다 |
| 확인과 정리 | 8분 | 나제 동맹의 성립과 결렬 순서, 왕과 한 일 짝짓기 |

## 학생이 자주 헷갈리는 점

1. 세 나라의 전성기 순서(백제 → 고구려 → 신라)와 한강 유역 주인의 순서를 따로 외워 서로 잇지 못한다.
2. 551년과 553년을 섞는다(함께 되찾음 → 신라가 하류까지 차지).
3. 한강 유역이 왜 중요한지(들판, 교통, 서해 바닷길)를 영토 넓이로만 생각한다.

## 핵심 내용(사실, 교육과정 수준의 통설)

- 4세기 후반 백제 근초고왕: 마한 정복, 371년 평양성 공격
- 5세기 고구려: 광개토 대왕의 요동 확보와 신라 구원(400), 장수왕의 평양 천도(427)와 한성 함락(475), 남쪽 경계 아산만~죽령 일대
- 6세기 신라: 법흥왕의 금관가야 병합(532), 진흥왕의 한강 유역 차지(551 상류, 553 하류), 대가야 정복(562), 함흥 일대 진출
- 나제 동맹: 433년 성립, 553년 결렬, 554년 관산성 전투에서 백제 성왕 전사

## 확인 문제

- 나제 동맹 사건 다섯 개 순서 배열
- 한 일과 왕 짝짓기(근초고왕, 장수왕, 진흥왕)
