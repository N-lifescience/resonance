# 일차함수의 그래프 — 기울기와 y절편을 상황으로 읽기

- 교과·학년: 중학교 2학년 수학
- 단원: 일차함수와 그래프 (2차시 중 2차시)
- 준비: 전자칠판, 학생 기기(실시간 수업을 쓸 때)

## 학습 목표

1. 일차함수의 그래프에서 기울기와 y절편을 찾을 수 있다.
2. 실생활 상황에서 기울기와 y절편이 무엇을 뜻하는지 설명할 수 있다.

## 수업 흐름 (45분)

| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 5분 | 집에서 300 m 떨어진 곳에서 출발해 1분에 60 m씩 걷는 상황. 걸은 시간과 집에서의 거리를 표로 보고 식을 세워 본다. |
| 전개 1 | 10분 | 기울기 = x가 1 늘 때 y가 변하는 양, y절편 = x가 0일 때 y의 값. 걷기 상황에서는 빠르기와 출발할 때의 거리다. 걷는 빠르기와 출발점을 바꿔 가며 그래프가 그려지는 모습을 본다. |
| 전개 2 | 10분 | 타는 초. 시간이 지날수록 길이가 준다. 기울기가 음수인 그래프와 x축과 만나는 점(다 탄 시각)을 읽는다. |
| 전개 3 | 10분 | 기본요금과 1분 요금이 다른 두 대여점. 이용 시간을 옮겨 가며 어느 곳이 더 싼지 견주고, 두 그래프가 만나는 점의 뜻을 말한다. |
| 정리 | 10분 | 확인 문제(상황을 식으로, 상황을 기울기 부호로 나누기, 그래프의 y절편 읽기)와 정리 |

## 핵심 내용

- 일차함수 y = ax + b에서 a는 기울기, b는 y절편이다.
- 기울기: x의 값이 1만큼 늘 때 y의 값이 변하는 양. a > 0이면 오른쪽 위로, a < 0이면 오른쪽 아래로 향한다.
- y절편: 그래프가 y축과 만나는 점의 y좌표. x = 0일 때 y의 값이다.
- 상황에서 기울기는 '단위 시간마다 변하는 양'(빠르기, 타는 빠르기, 1분 요금), y절편은 '처음 값'(출발할 때의 거리, 처음 길이, 기본요금)이다.
- 두 상황의 그래프가 만나는 점에서 두 값이 같다.

## 확인 문제

1. 길이 20 cm인 초가 1분에 0.4 cm씩 탄다. x분 뒤 남은 길이 y cm를 식으로 쓴다. (y = −0.4x + 20)
2. 여섯 가지 상황을 'x가 늘면 y도 는다', 'x가 늘면 y는 준다'로 나눈다.
3. 물탱크의 물이 빠지는 그래프에서 y절편 30이 뜻하는 것을 고른다.

## 유의점

- 걷기·초·대여 요금의 수치는 수업을 위해 정한 가상 자료다.
- 초가 다 탄 뒤에는 길이가 0에 머문다. 일차함수로 나타내는 범위는 다 탈 때까지다.
