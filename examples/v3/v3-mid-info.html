확인 문제 3

자료 10개를 선택 정렬로 정렬할 때 비교는 모두 몇 번일까?

자료가 n개이면 (n − 1) + (n − 2) + … + 1 = n(n − 1) ÷ 2번 견준다.

정리

  • 선택 정렬은 가장 작은 값을 골라 앞으로 보낸다. 교환이 적다.
  • 버블 정렬은 이웃한 두 값을 견주어 큰 값을 뒤로 보낸다.
  • 삽입 정렬은 정렬된 부분에 값을 끼운다. 거의 정렬된 자료에서 빠르다.
  • 선택 정렬과 버블 정렬은 자료 모양과 상관없이 n(n − 1) ÷ 2번 견준다.
  • 자료가 2배가 되면 비교 횟수는 약 4배가 된다.
